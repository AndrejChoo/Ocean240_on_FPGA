# Ocean240_on_FPGA
Реализация ретрокомпьютера "Океан 240" на FPGA

Процессор КР580ВМ80А HDL модель от vslav: https://github.com/1801BM1/vm80a.

ОЗУ и ПЗУ реализованы на микросхеме SRAM 512Kx16: в младшем байте микросхемы D[7:0] располагается ROM, а в старшем D[15:8] ОЗУ. Сама прошивка ПЗУ хранится в микросхеми SPI FLASH 25й серии и при запуске или сбросе переписывается в SRAM. В ПЗУ я записал 4 банка по 64Кб (ROM диски с "Монитором" и CP/M плюс программы), банки выбираются двумя джамперами или переключателями SW0,SW1. Прошивки и утилита для сборки ROM диска взяты из репозитория Алексея Морозова: https://github.com/alemorf/retro_computers.

Видеоконтроллер использует двухпортовую блочную RAM, синтезированную на FPGA. Видео выводится по HDMI. В видеоконтроллере не все палитры имеют оригинальные цвета, так как палитра из описания компьютера не соответствует реальным цвета, видимо, из-за инвертированного видеосигнала. Я подбирал цвета основной палитры, сравнивая с эмулятором. Цветной режим выводится в разрешении 800х600 с использованием скандаблера (512х512 с бордюром), монохромный режим выводится в разрешении 640х480 (512х256 плюс бордюр). Цвета монохромного режима я не подбирал. Все палитры можно править на свой вкус (массив цепей "palette"). Скроллинг реализован только вертикальный, горизонтальный просто нечем проверить.

Звук одноканальный выводится на обычный биппер.

Клавиатура: используется обычная USB клавиатура через переходник на STM32F411CEU (black pill с кварцем на 25MHz). Есть реализация для прошивки REL5(ASCII) и для REL8(матрица 7х11). 

Также реализован UART (Tx работает точно, Rx толком не тестировал, один байт принимается точно, а дальше не проверял). Скорость работы задаётся в ручную в соответствующих файлах.

В моём случае компьютер реализован на FPGA Altera Cyclone10LP (хотя достаточно будет Cyclone4E EP4CE6), и все файлы соответственно, от циклона. Чтобы переписать проект под ПЛИС других производителей, необходимо сгенерировать ip блоки PLL (main_pll), блочной памяти (VRAM) и, вероятно, подправить модуль HDMI, так как там используются специфические ip блоки ALTDDIO для вывода сигналов TMDS по фронту и по спаду клока, чтобы уменьшить частоту TMDS в два раза.

Реализация компьютера не полноценная, не такт в такт, так как описание делалось не со схемы, а функционально. Так что многое может не работать. Компьютер делался "по фану" ради развлечения. Выкладываю как есть, просто чтобы можно было "пощупать" этот древний артефакт.
